# 📋 ПАСПОРТ ПРОЕКТА

**Название:** Разработка ИИ-ботов для игры в Техасский Холдем (покер)  
**Тип:** Курсовая работа (6-й и 8-й семестры)  
**Дата:** 15 апреля 2026 г.  
**Статус:** Активная разработка

---

## 🎯 ЦЕЛЬ ПРОЕКТА

Создание и исследование интеллектуальных ботов для игры в Техасский Холдем с использованием различных подходов машинного обучения: генетических алгоритмов, Deep Q-Learning (DQN) и Actor-Critic (PPO-подобный алгоритм).

---

## 🏗 АРХИТЕКТУРА ПРОЕКТА

### Покерный движок (ядро)

| Компонент | Описание |
|-----------|----------|
| **Card/Deck** | Классы карт и колоды (52 карты) |
| **poker_hands/poker_rules** | Классификация и сравнение покерных комбинаций |
| **Game/GameManager** | Главный игровой цикл (preflop→flop→turn→river) |
| **HandCalculator** | Monte Carlo оценка силы руки (eval7, 200 итераций) |
| **Logger** | Singleton-логгер с буферизацией (80K сообщений) |

### Типы игроков

| Бот | Подход | Менеджер |
|-----|--------|----------|
| **SimpleGeneticBot** | 3-генный геном [hand_strength, bluff, bet_influence] | BotManager |
| **NeuralAgent (DQN)** | Deep Q-Network (4 слоя × 64 нейрона) | NeuralAgentManager |
| **NeuralACAgent** | Actor-Critic (on-policy, PPO-подобный loss) | NeuralACAgentManager |
| **RandomPlayer** | Случайный выбор действий | RandomPlayerManager |
| **CallingPlayer** | Всегда call | CallingPlayerManager |

## 📊 ТЕКУЩЕЕ СОСТОЯНИЕ

### Кодовая база
- **66 Python-файлов** (включая старый и новый код)
- **18 экспериментальных скриптов** в `Experiments/`
- **Тесты:** pytest fixtures для покерных комбинаций

## ⚙️ ПАРАМЕТРЫ ОБУЧЕНИЯ

### Actor-Critic (основной подход)
- State vector: 7 измерений (10 для GPU-моделей)
- Batch size: 2048 (`NNData.BATCH_SIZE`)
- Entropy: decay от 0.01 до 0.005
- Gradient clipping: `max_norm=1.0`
- On-policy обучение с PPO-подобным loss
- GPU-поддержка

### Генетический алгоритм
- Популяция: 10 ботов
- Геном: 3 гена [hand_strength, bluff, bet_influence]
- Операции: кроссовер, мутация
- 120+ поколений эволюции
